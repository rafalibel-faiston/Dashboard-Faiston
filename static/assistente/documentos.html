Sinalizações proativas (capacidade D)

O job de verdade roda sozinho de madrugada. Sem dado real acumulado ainda, use "Gerar dados de teste" pra criar tarefas sintéticas (marcadas com o cliente "Cliente Teste Observar") que disparam os três detectores, depois "Rodar detecção agora" pra ver a sinalização aparecer. "Limpar dados de teste" remove só o que foi gerado aqui — nunca toca em tarefa real. Tudo admin-only, mesmo gate desta tela.

"Ver diagnóstico" mostra só contagem e data das sinalizações do ID acima (orçamento usado, cooldown) — nunca o texto gerado nem o feedback dado, isso continua só da pessoa.
